# 🌺 ColorGrid-Tx 🌺 〜鬼ヤバ光学式2Dグリッド伝送プロトコル＆アプリマニュアル〜 (Manual v1.9.12)

やっほー！✨ ColorGrid-Tx の世界へようこそ！🥺💖
このアプリは、一般的なウェブカメラやスマホカメラを使って、PC画面にピカピカ光るカラー格子マトリクスからデータを超高速・超耐久で読み取る「光学式ビットデータ転送システム」の決定版だよ！✌️🔥

画像全体を 32x32 ピクセルごとの微細なローカルブロックに分割し、輝度(min+max)/2を閾値にとる「適応的ブロック閾値」を採用。部屋の半分が影になっていても、1ピクセル単位で最高の二値化ができるお！さらに、1:1:3:1:1比率の許容誤差を「0.5」「0.8」「1.2」の3段階で総当たりリトライ！見つかったファインダー候補は、従来のなんと1.5倍に拡張されたマージ境界で優しくまとめて一発吸収。「diagonal check」による無理な弾きを防止し、ノイズを完全に寄せ付けない最強仕様にレベルアップしたよ！さらにiOSスマホカメラにありがちな「近づけすぎて物理限界で大ボケするバグ」を、1080PフルHD起動とWebRTC動的ズーム、そして非対応環境（iOS Safariなど）でも快適にピントが合う2.0xデジタルインキャンバス・ズームを備えた**「ダブル・ズーム・ハイブリッド・エンジン」**と、画面をぽんと叩くだけで一瞬でフォーカスを合わせ直す**「液晶タップ任意オートフォーカス」**を導入して完全無双！マジですごくない！？✨

    *   同じチャンクを何十回も重複ロードしない超効率設計！受信ノード側には「SF映画のハッカー画面」みたいな超カッコいい進捗状況タイルのグリッドが出るから、残りあと何チャンクかが一発で分かるよ！💖

    *   ペイロード領域にも約25%の冗長誤り訂正を上乗せしているから、多少のノイズや反射で色データがバグっても、自動修復されて元通りになるから安心！ウケる！

    *   閾値から30以内の曖昧（どちらとも言えない）なセルは無理に決めつけず「消失（-1）」としてマーク！これによって無駄な誤作動を完全にカットし、RSデコーダの強力な消失訂正ポテンシャルを背後からガッチリ支える完璧な連携体制を組んでるよ！ヤバくない！？✨

## 🛠 プロトコルの幾何学的構造（インフラ）

```
     [TL Finder (7x7)] ------------------- [TR Finder (7x7)]
             |   W H W H W H W H w ...             |
             |   H [ 基準パレット(8色) ]            |
             |   W [同期クロックセル]              |
             |                                     |
             |                                     |
             |                             [Alignment Pattern]
             |                                  (7x7)
             |                                 中心座標:
             |                                (size-6, size-6)
     [BL Finder (7x7)] --------------------------- +
```

*   **ファインダーパターン (7x7 / 3個)**:
    左上 (TL)、右上 (TR)、左下 (BL) に配置され、`1:1:3:1:1` のアスペクト比率を持つ同心正方形です。どんなに画面が歪んでいても、初期的なコードの輪郭とパースペクティブを秒速でロックオン！
*   **基準パレット (8色 / 1x8)**:
    左上ファインダーのすぐ右。カメラが受光する物理的なRGBの各基準を瞬時にキャリブレーションし、色の識別精度を自動チューニングするよ。
*   **同期クロックマーク (1x1)**:
    基準パレットのすぐ下。フレーム更新に合わせて白/黒がパタパタと切り替わり、受信側が「新しいチャンクが映ったこと」を正確に認識するよ！
*   **アライメントパターン (7x7 / 1個)**:
    右下に配置。斜めから撮影した際に、右下セルの読み取り位置がズレないよう、極小サブピクセルスキャンで真の中心を完全に吸着・校正するスーパーアンカーだよ✨

## 📖 アプリのおすすめな使い方！

### 📤 データを送る（送信モード）
1.  **テキストやファイルを入力**:ペイロードソースに好きな文字列を入れるか、任意のファイルをドロップしてね。
2.  **パラメータを選ぶ**:
    *   **プロファイル**: 送りたいデータの長さに合わせて、`Micro (XS)` から `Extra Large (XL)` まで選べるよ。
    *   **同期FPS**: 1秒間に切り替えるアニメーションフレーム数。カメラ性能に合わせて `8 〜 12` くらいがイチオシ！
    *   **双方向インタラクティブ同期**: これをONにすると、背面カメラが起動して、受信側からのフィードバックコード（ACK）を手ぐすね引いて監視し始めるよ！
3.  **「送信開始」をクリック**: カラーのカラーコードがチカチカ放流され始めるよ！「TX_CHUNK」で今何チャンク目かをリアルタイムにお知らせするよ。

### 📥 データを受ける（受信モード）
1.  **「受信モード」を選択**:
    *   受信バッファはモード変更時やスキャナー起動時にピカピカに初期化されるよ！
2.  **「スキャナー起動」をクリック**: カメラの映像がONになり、認識用オーバーレイ（緑色のハッカーっぽい枠線）が表示されるよ。
3.  **「双方向インタラクティブ同期」をONにする**:
    *   ONにすると、画面の右下に極小(XS)のフィードバックコードがピコリと出現するよ！
4.  **カメラを送信画面にかざす**:
    *   画面いっぱいに ColorGrid コードを収めるようにしてね。
    *   コードを認識してロックされると、**「CHUNK RECEIVE MATRIX」**のグリッドが点灯し始めるよ！
    *   **黄色（Awaiting）**: 今受信を待ち受けている（該当）チャンク！
    *   **ピンク（Received）**: 1回でも受信成功して、すでにバッファにキープしたチャンク！
    *   **グレー（Pending）**: これから受け取るチャンクたち。
5.  **魔法の双方向フィードバック自動修復**:
    *   もし障害物やブレで 2番、3番チャンクだけを綺麗に逃した（欠落させた）としても、右下のフィードバックコードが「F:2,3」へと自動トランスフォーム！
    *   送信側のカメラがそれを読み取ることで、送信側が瞬時に**2番と3番のみに送信を絞って交互にチカチカ再送開始！**
    *   欠落が埋まった瞬間、送信側は完了を検出して自動停止アニメーションへ！すべてのマスがピンクになると **「ALL CHUNKS FULLY RECOVERED! 🎉」** が表示され、テキストやバイナリファイルが 100% 完璧に復元されるよ！ダウンロードボタンから直接DLしてね！

## 💖 ギャルからのワンポイントアドバイス
「なんかうまく認識しないみ💦」ってときは、次の3つをチェックしてみて！
*   **部屋の明かりが反射してない？**: 画面に照明の光が写り込むと色がバグっちゃうから、少しカメラの角度を斜めに傾けて反射を逃すと、アライメント校正と合わさって 鬼のスピードでロック されるよ！
*   **ピントが合ってる？**: カメラがボケすぎていると、ファインダーパターン検出が迷走しちゃう。ピントがカチッと合う距離にスマホを固定するのが正解！
*   **明るさをチェック**: 画面が明るすぎたり暗すぎたりする場合は、基準パレットが見えるよう、モニターの輝度やカメラの露出をちょっと調整してみてねお！
