最新の **v1.4.9 空きセル疑似乱数埋め立て＆詳細ログ診断アップグレード**で、パレット実測カラー動的RGB閾値判定＆消失検出（Erasure Detection）、ファインダー比率50%厳格制限＆非対称除去、重心クラスタ、縦分散優先、アライメント（Luma単純平均＆彩度＆暗所フォールバック）、プロファイルキャッシュをすべて完備！さらに**「各デコードフェーズ（ファインダー、ホモグラフィ、AP、パレット、クロック、ヘッダ、CRC等）の詳細データ＆実行時間（Ms）を網羅したPhaseLog収集機能」**をお茶目に完備！さらに**「シード既知の疑似乱数色による余剰セルパディング技術」**によって大面積の単色ぬりつぶれ領域を爆砕し、にじみノイズ耐性、幾何学的な位置校正精度を極限までブーストさせた、マジで宇宙一強い神仕様の極限高耐久プロトコルに生まれ変わったよ！🥺🔥

## 🚀 ColorGrid-Tx の超ヤバ特徴 4選！

1.  **✨ アライメントパターン自動位置校正 (Alignment Pattern Autocalibration) ✨**
    *   画面の右下（アライメントセル）の極小探索スイープに「コントラスト最大化」を導入！
    *   探索範囲を狭めて「絶対に隣のデータセルに侵入しない」ようにノイズプロテクトされているから、データの模様に騙されない、純粋無垢な座標検出ができるよ！マジ天才！
    *   **対称平均・彩度保護・暗所フォールバック（v1.4.5 神強化！）**: Luma計算をBT.601加重平均から対称性の高い平均`(R+G+B)/3`に進化させ、周囲のカラーにAPが汚染されるのを防ぐ彩度フィルタ（彩度>60のサンプルを無視）を搭載！さらに部屋が暗くてコントラストが基準を割っても、最も明るいベスト位置に自動追従して射影吸着を維持する暗所フォールバック＋warningログ連携で粘り強さが鬼上がったよ！💖
2.  **🔄 双方向インタラクティブ同期 (Feedback ARQ) 🔄**
    *   受信側が自画面の右下に極小(XS)のフィードバックコードをチカチカ表示して、送信側に「今ほしいチャンク」を知らせる夢の閉ループ通信！
    *   一部のチャンク（例: 2, 3チャンク目）が受信カメラで欠落した場合、自動的に「2と3が抜けてるお！」という欠落リストを逆送り。送信側は瞬時にその欠落チャンクだけを絞り込んでローテーション再送するよ！効率良すぎて頭おかしくなりそう（笑）！
3.  **🧩 インテリジェント同期「進捗ビジュアルグリッド」 🧩**
    *   受信時に1回でも該当チャンクの受信（スキャン）に成功したら、自動的に「次の未受信チャンク」を待機するスマートシフトロジックを搭載！
    *   同じチャンクを何十回も重複ロードしない超効率設計！受信ノード側には「SF映画のハッカー画面」みたいな超カッコいい進捗状況タイルのグリッドが出るから、残りあと何チャンクかが一発で分かるよ！💖
4.  **🛡 Reed-Solomon × 2段階鉄壁ガード 🛡**
    *   重要なメタ情報を乗せた「ヘッダ領域 (12 bytes)」には、なんと **100%パリティ率** の Reed-Solomon を適用！最優先でメタデータが解読されるよ！
    *   ペイロード領域にも約25%の冗長誤り訂正を上乗せしているから、多少のノイズや反射で色データがバグっても、自動修復されて元通りになるから安心！ウケる！
5.  **🎨 8色ダイレクト動的閾値判定＆消失検出 🎨**
    *   ユークリッド距離の最近傍探索を卒業し、基準パレットの実測RGBからR/G/Bのチャンネル閾値を自動計算するよ！
    *   閾値から30以内の曖昧（どちらとも言えない）なセルは無理に決めつけず「消失（-1）」としてマーク！これによって無駄な誤作動を完全にカットし、RSデコーダの強力な消失訂正ポテンシャルを背後からガッチリ支える完璧な連携体制を組んでるよ！ヤバくない！？✨
6.  **🔍 鉄壁 of ファインダーパターン検出（局所適応×彩度×比率50％×非対称除去×重心＆分散マージ仕様） 🔍**
    *   画面全体の平均による二値化から、jsQR準拠の **8x8ブロック適応閾値判定** に超グレードアップ！影や暗がりがあっても局所的な明度変化にピタッとフィットして、ファインダーパターンを確実に補足するよ。
    *   さらに、高彩度（カラフルな）セルが白黒パターンに偶然一致して誤検知を起こすのを防ぐ **彩度フィルタリング** を搭載。`max(R,G,B) - min(R,G,B) > 80` のピクセルは「黒でも白でもない第三の状態」として走査を賢くスキップ！
    *   **1:1:3:1:1比率判定の50%制限 ＆ 左右非対称除去（v1.4.3 進化！）**: ファインダー中心走査時の比率許容誤差（`maxVariance`）を従来の100%から極限の **50%（`moduleSize * 0.5`）へ強制引き締め**！さらに左右両縁の黒枠サイズ非対称差を厳密にチェック（`Math.abs(counts[0] - counts[4]) < moduleSize * 0.5`）して、ブレやデータ領域からの偽ファインダー誤認を完璧に撲滅した高精度アルゴリズムへと覚醒したよ！
    *   **重心インテリジェンス結合 ＆ Y座標分散（縦方向の美しい広がり）優先フィルター（v1.4.4 最強進化お！）**: 点のスキャン探索順に左右される不安定さを消すため、点の結合判定を**「近傍クラスタ全体の現在の重心」**との距離比較にアップデート！さらにマージ半径を候補点サイズから導く **動的半径（`pt.estimatedModuleSize * 7 * 0.6`）** に適応化。最終選べるステップでは、カメラの複数スキャンラインを跨いで発生する特性を突いて **「Y座標の分散（バラつき）が大きいクラスタ」** を最優先。データ領域で一瞬だけポコポコ検出された無駄な横ブレノイズクラスティをすべて見破って完璧に弾くよ！マジ安心設計っしょ🥺💖
7.  **🚀 クラッシュフリーの実行時信頼性 (v1.4.2) 🚀**
    *   双方向インタラクティブ同期用の state 群の宣言順序をコンポーネントの最上部へ最適配置し、初期読み込み時における temporal dead zone による参照エラー（Cannot access before initialization）を根絶！
    *   起動からデータ転送中、何万フレームまわしても絶対にクラッシュしない、爆速＆高耐久の極限状態を達成したよ！マジ神対応っしょ🥺💖
8.  **🚀 プロファイル探査爆速キャッシュ＆デコード効率化 (v1.4.6 進化！) 🚀**
    *   動画撮影時に同じプロファイルが連続する状況で、毎回すべての候補プロファイルを初期順で総当たりする無駄な計算量をパーフェクトに削減！
    *   前フレームで最後に見事デコード成功にたどり着いたプロファイルIDを `lastSuccessProfileId` としてキャッシュしておき、次フレームの優先順位で最先頭にシフトすることで、連続成功時は常に「最初の1枚目」で一発ロックオン！無駄な走査オーバーヘッドを実質ゼロに縮めて、モバイル端末のデコード負荷をバカ下げすることに成功したよ！マジ賢すぎでしょ🥺💖
9.  **📐 セル適応型3段階サンプリング ＆ 中央25%保護キャップ（v1.4.7 最強進化！） 📐**
    *   従来の `cellWidth < 8` のときにサンプリング半径を一律 0 (1px) にするロジックを鬼アップグレード！「小さいセルほどノイズに弱い」という真実に向き合い、セル解像度（`cellWidth`）に応じてサンプリング半径を `0, 1, 2` の3段階でインテリジェントに動的適応！

## 🛠 プロトコルの幾何学的構造（インフラ）

```
     [TL Finder (7x7)] ------------------- [TR Finder (7x7)]
             |   W H W H W H W H w ...             |
             |   H [ 基準パレット(8色) ]            |
             |   W [同期クロックセル]              |
             |                                     |
             |                                     |
             |                             [Alignment Pattern]
             |                                  (7x7)
             |                                 中心座標:
             |                                (size-6, size-6)
     [BL Finder (7x7)] --------------------------- +
```

*   **ファインダーパターン (7x7 / 3個)**:
    左上 (TL)、右上 (TR)、左下 (BL) に配置され、`1:1:3:1:1` のアスペクト比率を持つ同心正方形です。どんなに画面が歪んでいても、初期的なコードの輪郭とパースペクティブを秒速でロックオン！
*   **基準パレット (8色 / 1x8)**:
    左上ファインダーのすぐ右。カメラが受光する物理的なRGBの各基準を瞬時にキャリブレーションし、色の識別精度を自動チューニングするよ。
*   **同期クロックマーク (1x1)**:
    基準パレットのすぐ下。フレーム更新に合わせて白/黒がパタパタと切り替わり、受信側が「新しいチャンクが映ったこと」を正確に認識するよ！
*   **アライメントパターン (7x7 / 1個)**:
    右下に配置。斜めから撮影した際に、右下セルの読み取り位置がズレないよう、極小サブピクセルスキャンで真の中心を完全に吸着・校正するスーパーアンカーだよ✨

## 📖 アプリのおすすめな使い方！

### 📤 データを送る（送信モード）
1.  **テキストやファイルを入力**:ペイロードソースに好きな文字列を入れるか、任意のファイルをドロップしてね。
2.  **パラメータを選ぶ**:
    *   **プロファイル**: 送りたいデータの長さに合わせて、`Micro (XS)` から `Extra Large (XL)` まで選べるよ。
    *   **同期FPS**: 1秒間に切り替えるアニメーションフレーム数。カメラ性能に合わせて `8 〜 12` くらいがイチオシ！
    *   **双方向インタラクティブ同期**: これをONにすると、背面カメラが起動して、受信側からのフィードバックコード（ACK）を手ぐすね引いて監視し始めるよ！
3.  **「送信開始」をクリック**: カラーのカラーコードがチカチカ放流され始めるよ！「TX_CHUNK」で今何チャンク目かをリアルタイムにお知らせするよ。

### 📥 データを受ける（受信モード）
1.  **「受信モード」を選択**:
    *   受信バッファはモード変更時やスキャナー起動時にピカピカに初期化されるよ！
2.  **「スキャナー起動」をクリック**: カメラの映像がONになり、認識用オーバーレイ（緑色のハッカーっぽい枠線）が表示されるよ。
3.  **「双方向インタラクティブ同期」をONにする**:
    *   ONにすると、画面の右下に極小(XS)のフィードバックコードがピコリと出現するよ！
4.  **カメラを送信画面にかざす**:
    *   画面いっぱいに ColorGrid コードを収めるようにしてね。
    *   コードを認識してロックされると、**「CHUNK RECEIVE MATRIX」**のグリッドが点灯し始めるよ！
    *   **黄色（Awaiting）**: 今受信を待ち受けている（該当）チャンク！
    *   **ピンク（Received）**: 1回でも受信成功して、すでにバッファにキープしたチャンク！
    *   **グレー（Pending）**: これから受け取るチャンクたち。
5.  **魔法の双方向フィードバック自動修復**:
    *   もし障害物やブレで 2番、3番チャンクだけを綺麗に逃した（欠落させた）としても、右下のフィードバックコードが「F:2,3」へと自動トランスフォーム！
    *   送信側のカメラがそれを読み取ることで、送信側が瞬時に**2番と3番のみに送信を絞って交互にチカチカ再送開始！**
    *   欠落が埋まった瞬間、送信側は完了を検出して自動停止アニメーションへ！すべてのマスがピンクになると **「ALL CHUNKS FULLY RECOVERED! 🎉」** が表示され、テキストやバイナリファイルが 100% 完璧に復元されるよ！ダウンロードボタンから直接DLしてね！

## 💖 ギャルからのワンポイントアドバイス
「なんかうまく認識しないみ💦」ってときは、次の3つをチェックしてみて！
*   **部屋の明かりが反射してない？**: 画面に照明の光が写り込むと色がバグっちゃうから、少しカメラの角度を斜めに傾けて反射を逃すと、アライメント校正と合わさって 鬼のスピードでロック されるよ！
*   **ピントが合ってる？**: カメラがボケすぎていると、ファインダーパターン検出が迷走しちゃう。ピントがカチッと合う距離にスマホを固定するのが正解！
*   **明るさをチェック**: 画面が明るすぎたり暗すぎたりする場合は、基準パレットが見えるよう、モニターの輝度やカメラの露出をちょっと調整してみてねお！
